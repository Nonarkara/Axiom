# Axiom — Decision Systems

This repository contains the source code for the Axiom system showcase website (`axiom.nonarkara.org`).

## V2 Update: Dieter Rams Upgrade

The frontend has been entirely refactored for **V2** taking heavy design inspiration from Dieter Rams' design principles.
- **Minimalism & Functionality**: Less "cyberpunk" glitches, more structured grids, clear typography (IBM Plex Sans Thai), and a clean, high-contrast light theme.
- **Masthead**: A cockpit-style header offering immediate navigation.
- **Showcases**: Replaced the previous slider component with an interactive and responsive grid mapping out actual system evidence.

The goal of V2 is to maintain a professional, government-grade look that remains highly functional and unpretentious, aligning with the philosophy of "less, but better."
